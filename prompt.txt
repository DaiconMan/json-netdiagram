あなたはネットワーク構成図のJSONを作る係です。画像は作らず、下のスキーマに従ったJSONだけを1つのコードブロックで出力してください。説明文は不要です。

【スキーマ】
{
  "canvas": { "title": "図のタイトル", "font_size": 14, "row_gap": 150, "col_gap": 60 },
  "nodes": [
    { "id": "英数字の一意なID", "label": "表示名（改行は \n）", "layer": 行番号, "col": 列番号, "type": "種類" }
  ],
  "edges": [
    { "from": "ID", "to": "ID", "label": "回線種別など（省略可）", "style": "solid", "arrow": false, "label_pos": 0.5 }
  ],
  "groups": [
    { "id": "英数字ID", "label": "グループ名", "nodes": ["ID", "ID"], "padding": 20 }
  ]
}

【ルール】
- layer は上から 0,1,2…（上流ほど小さい。Internet→FW→コア→フロア→端末の順）
- col は左から 0,1,2…。全ノードに必ず付ける。同じ layer と col の組み合わせを2つ作らない
- x, y, w, h は使わない（位置とサイズは変換側で計算する）
- type は firewall / switch / router / server / cloud / user のどれか
- label は1行あたり全角12文字・半角24文字以内。長ければ \n で改行（3行まで）
- edges の from/to は nodes に存在する id だけを使う
- 線は隣接する layer の間を基本とし、途中のノードの真上を通る結び方を避ける（必要なら col をずらす）
- group に入れるノードは col が連続する範囲にまとめ、グループ外のノードをその範囲の中に置かない
- 別グループ同士は col を1つ以上空ける
- 線ラベルがグループの枠をまたぐ線は "label_pos": 0.25 などで枠の外側に寄せる
- JSONにコメントや末尾カンマを入れない
- edges の style は solid か dashed（無線・論理接続は dashed）

【構成】
（ここに構成を書く。箇条書きでOK。例）
- Internet → FortiGate 200F（本社FW）
- FW → Core SW（Catalyst 9300）10GbE、FW → DMZ SW 1GbE
- Core SW 配下: 1F フロアSW、2F フロアSW、社内サーバ（AD/ファイル、LACP x2）
- DMZ SW 配下に公開Web。DMZと社内LANはそれぞれグループ
- 1F フロアSW 配下に Meraki MR（PoE、点線）、2F 配下に PC
